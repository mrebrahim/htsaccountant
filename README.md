# HTS Media ERP — نظام إدارة الموارد

نظام متكامل لإدارة الحسابات المالية والعملاء والموظفين وميزانيات وحملات إعلانات فيسبوك لشركة HTS Media.
واجهة عربية بالكامل باتجاه RTL، متجاوبة مع الموبايل.

## الأقسام
| القسم | الوصف |
|---|---|
| لوحة التحكم | الإيرادات، المصروفات، صافي الربح، العمولات، الممول، الصرف الإعلاني، أرصدة العملاء والحسابات، رسم بياني لآخر 12 شهر |
| الحسابات المالية | إضافة/تعديل/حذف الإيرادات والمصروفات، التصنيفات (ثابتة، متغيرة، نثريات، عملاء، حملات، رواتب)، فلترة بالنوع والتصنيف والعميل وشهر أو عدة شهور، تحديث الإجماليات تلقائياً، تصدير Excel |
| العملاء | بيانات العميل، نسبة العمولة، السجل المالي، الحسابات الإعلانية والحملات المرتبطة، كشف حساب Excel |
| ميزانيات الإعلانات | التمويل لكل حساب، الصرف الفعلي الشهري (من Facebook API أو يدوياً)، **صافي الرصيد = الممول − الصرف الفعلي**، حسابات مملوكة / شريك / عميل |
| الحملات الإعلانية | مزامنة الحملات وأدائها من فيسبوك (للمدير فقط)، ربطها بالعملاء والحسابات، الإيرادات والمصروفات المرتبطة |
| الموظفين | الرواتب، السلف، الخصومات، المكافآت، التعديلات، كشف رواتب شهري، تسجيل المدفوعات تلقائياً كمصروفات |
| التقارير | تقرير أرباح وخسائر شهري/سنوي، رسوم بيانية أعمدة وخطوط (Recharts)، توزيع حسب التصنيف، فلاتر وتصدير Excel |
| المستخدمين | أدوار (مدير / مستخدم) وصلاحيات لكل قسم، كلمات مرور مشفرة bcrypt |
| الإعدادات | اسم الشركة، العملة، رمز Facebook Ads API (للمدير فقط) |

## التقنيات
React 19 · Tailwind CSS 4 · Express + tRPC 11 · Drizzle ORM · PostgreSQL (Supabase) · Recharts · SheetJS · Facebook Marketing API

> ملاحظة: المواصفات ذكرت MySQL/TiDB، لكن تم استخدام Postgres على Supabase لأنه المتاح في الحساب. Drizzle يجعل التحويل لـ MySQL ممكناً بتعديل `server/db`.

## التشغيل محلياً
```bash
npm install
cp .env.example .env   # ضع DATABASE_URL و JWT_SECRET
npm run dev            # الواجهة على 5173 والخادم على 3001
```
عند أول تشغيل ستظهر شاشة **إعداد النظام** لإنشاء حساب مدير النظام.

## قاعدة البيانات
- المخطط في `server/db/schema.ts`، وملفات SQL في `drizzle/`.
- تم تطبيق المخطط على مشروع Supabase `accountant` مع تفعيل RLS على كل الجداول (بدون سياسات) بحيث لا يمكن الوصول للبيانات عبر واجهة Supabase العامة — الخادم فقط يتصل مباشرة.
- لتعديل المخطط: `npm run db:generate` ثم `npm run db:push`.

## النشر على Vercel
1. اربط المستودع بمشروع Vercel (الإعدادات في `vercel.json`؛ الـ API في `api/index.ts`).
2. أضف متغيرات البيئة:
   - `DATABASE_URL` — من Supabase: Project Settings → Database → Connection string → **Transaction pooler** (منفذ 6543).
   - `JWT_SECRET` — نص عشوائي طويل.
   - `FB_ACCESS_TOKEN` (اختياري) — أو أدخله من صفحة الإعدادات.

## Facebook Ads
استخدم System User Token بصلاحية `ads_read`. من صفحة الإعدادات أدخل الرمز ثم:
- **ميزانيات الإعلانات → استيراد من فيسبوك** لإضافة الحسابات.
- **مزامنة الصرف** لجلب الصرف الفعلي الشهري لكل حساب.
- **الحملات → مزامنة من فيسبوك** لجلب الحملات وأدائها.
