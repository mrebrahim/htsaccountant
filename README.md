# HTS Media ERP — نظام إدارة الموارد

نظام حسابات الإيرادات والمصروفات لشركة HTS Media للتسويق الإلكتروني. كل البيانات تُدخل يدوياً.
واجهة عربية بالكامل باتجاه RTL، متجاوبة مع الموبايل.

## الأقسام
| القسم | الوصف |
|---|---|
| لوحة التحكم | الإيرادات، المصروفات، صافي الربح، العمولات، تمويل وصرف الإعلانات، أرصدة العملاء، رسم بياني لآخر 12 شهر |
| الحسابات المالية | إضافة/تعديل/حذف الإيرادات والمصروفات، فلترة بالنوع والتصنيف والعميل وشهر أو عدة شهور، تصدير Excel |
| العملاء | بيانات العميل، نسبة العمولة، السجل المالي، كشف حساب Excel |
| ميزانيات الإعلانات | تسجيل المبالغ المحولة لكل حساب إعلاني والصرف الفعلي الشهري يدوياً — **صافي الرصيد = الممول − الصرف الفعلي** |
| الحملات الإعلانية | تسجيل الحملات وأدائها يدوياً وربطها بالعملاء |
| الموظفين | الرواتب، السلف، الخصومات، المكافآت، كشف رواتب شهري، تسجيل المدفوعات كمصروفات تلقائياً |
| التقارير | أرباح وخسائر شهري/سنوي، رسوم بيانية، توزيع حسب التصنيف، تصدير Excel |
| المستخدمين | أدوار (مدير / مستخدم) وصلاحيات لكل قسم، كلمات مرور مشفرة |

### تصنيفات الإيرادات
باقات شهرية / عقود عملاء · إدارة حملات إعلانية · تصميم ومحتوى وفيديو · مواقع وبرمجة · عمولات · إيرادات أخرى

### تصنيفات المصروفات
صرف إعلانات / تمويل حسابات · رواتب وسلف · فريلانسرز · اشتراكات وأدوات · مصروفات ثابتة · مصروفات متغيرة · نثريات · مصروفات على عملاء

## التقنيات
Next.js 16 (App Router) · React 19 · Tailwind CSS 4 · tRPC 11 · Drizzle ORM · PostgreSQL (Supabase) · Recharts · SheetJS

## التشغيل محلياً
```bash
npm install
cp .env.example .env   # ضع DATABASE_URL و JWT_SECRET
npm run dev            # http://localhost:3000
```
عند أول تشغيل تظهر شاشة إعداد النظام لإنشاء حساب مدير النظام.

## هيكل المشروع
- `app/` — صفحات Next.js و API (`app/api/trpc`, `app/api/health`)
- `views/` — واجهات الصفحات، `components/` — مكونات مشتركة
- `server/` — منطق الخادم (tRPC routers، قاعدة البيانات، المصادقة)
- `shared/constants.ts` — التصنيفات والصلاحيات والنصوص العربية

## قاعدة البيانات
المخطط في `server/db/schema.ts` وملفات SQL في `drizzle/`. جداول Supabase محمية بـ RLS والخادم فقط يتصل بها.

## النشر
المشروع منشور على Vercel ويتحدث تلقائياً مع كل push. متغيرات البيئة المطلوبة: `DATABASE_URL` و `JWT_SECRET`.
